# Banking SQL Mastery Project

## Project Overview

This project is a hands-on SQL and Data Analytics learning platform built using a banking transactions dataset.

The objective is to strengthen advanced SQL query-writing skills, explore analytical capabilities using DuckDB, and perform data analysis using Python and Pandas.

## Dataset Overview

The project uses a banking dataset containing the following tables:

| Table | Description |
|---|---|
| BRANCHES | Bank branch information |
| CUSTOMERS | Customer details |
| ACCOUNTS | Customer account information |
| MERCHANTS | Merchant details |
| TRANSACTIONS | Banking transaction records |

The dataset contains approximately 320,000 transaction records.

## Technology Stack

- **SQL:** Advanced SQL, Joins, Subqueries, CTEs, Window Functions
- **Database:** DuckDB, Oracle Database 10g XE
- **Python:** Pandas, NumPy
- **Data Formats:** Parquet, CSV
- **Development Environment:** VS Code
- **Version Control:** Git and GitHub

## Learning Objectives

1. Develop advanced SQL query-writing skills.
2. Practise complex joins, subqueries and CTEs.
3. Master SQL window functions and analytical queries.
4. Explore DuckDB for analytical data processing.
5. Use Python and Pandas for data validation and analysis.
6. Practise Oracle SQL, PL/SQL and SQL*Loader.
7. Apply Git and GitHub for project version control.

## Business Analysis Use Cases

- Top customers based on transaction value.
- Monthly transaction trends.
- Customer transaction behaviour.
- Top merchants by transaction category.
- Transaction pattern analysis.
- Customer account analysis.
